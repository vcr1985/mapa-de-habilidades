# Etapa 1 – Inventário de Habilidades

Esta etapa tem como objetivo identificar todas as habilidades desenvolvidas ao longo da trajetória acadêmica, profissional e pessoal.

## Habilidades Identificadas

### Técnicas
- Lógica de programação
- Uso de sistemas e plataformas digitais
- Organização de dados e informações
- Noções de desenvolvimento backend
- Uso de banco de dados (MySQL)
- Fundamentos de redes e segurança da informação

### Cognitivas
- Raciocínio lógico
- Capacidade de análise
- Aprendizado autodidata
- Resolução de problemas

### Comportamentais
- Organização
- Persistência
- Curiosidade
- Responsabilidade
- Interesse contínuo por tecnologia

Este inventário serve como base para as próximas etapas do projeto.
